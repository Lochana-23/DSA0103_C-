## Overview

This repository contains **Assignment 1** for the Object-Oriented Programming (OOP) course. The assignment focuses on designing, implementing, and validating the fare logic of a city metro smart-card system using C++.

The work covers fundamental C++ concepts, object-oriented programming principles, fare calculations, smart-card balance validation, input handling, test cases, and design improvements.

## Objectives

- Understand C++ data types, constants, operators, and type conversions.
- Apply OOP concepts to model a metro smart-card system.
- Implement fare calculation based on travel zones and peak-hour conditions.
- Validate card balance and minimum-balance requirements.
- Handle invalid inputs safely.
- Test fare logic using multiple test cases.
- Compare procedural and object-oriented approaches.
- Evaluate scalability, maintainability, and possible system extensions.
